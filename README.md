# E-Learning_Platform

  Project developed with the aim of improving frontend developer skills. E-DUCATION is an application dedicated to the field of learning. The roles areProfessor - who can create, delete, and edit courses, view statistics, and see student attendance. Students can search for and enroll in courses based on the period they want, the course search mode being complex and including various filters (e.g., price, course name, period), they also benefit from an AI Chatbot called E-Bot.

  The backend part of the project is built in Node.js, and the frontend part is in React + Vite. The application design was created in Figma, which can be found at the following link:
